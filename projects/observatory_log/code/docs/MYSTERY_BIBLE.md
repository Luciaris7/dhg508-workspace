## 1 世界与传言

- 地点：**白桦湖 / Birch Lake**（用户要求"更符合现实的地名，日常恐怖"；只出现在文本里，改名只需替换 `txt.gd` / `txt_zh.gd`）。
- 传言：每 13 年一次，湖面上空出现血红色极光，持续约一周；有人看见湖心立着一座建筑。
- 年份全部按游戏日期动态计算（游戏日期 = 首次游玩的真实日期，见 `G.day_unix`）：
  - 本周期年份 `Y`（第 04 周期，玩家）
  - `{y1}` = Y−13（第 03 周期，上一任）
  - `{y2}` = Y−26（第 02 周期）
  - `{y3}` = Y−39（第 01 周期，站点启用）
  - `{yn}` = Y+13（第 05 周期，"未来日志"）
- 传达方式（前 5 分钟内）：序章语音留言第 3 句直接说出传言；Day 1 下车后几步路就是告示牌（线索 1）。

## 2 当前设定

第七站负责记录白桦湖上空的血红极光、湖心建筑和星图中的异常天体。每十三年，站点会安排一名观测员值守七夜，按照工作须知完成天线、测绘、星图和汇报。

| 环节 | 作用 |
| --- | --- |
| 天线 | 指向湖心上方，获取观测方向 |
| 湖面回声测绘 | 记录湖底结构的位置和变化 |
| 星图 | 记录不在正常星历中的暗红天体 |
| 汇报 | 提交当天图像是否异常的记录 |
| 第七日湖岸 | 完成这一周期的最后观测 |

湖心建筑、血红极光、暗红天体和湖底结构之间存在联系，但它们究竟是实体、异象还是投影，保留到结局中。普通流程会把观测员带到湖边并进入献祭或同化结局。收集线索、解开电台数字并完成逃离准备，可以中断流程。

刻意保留未知的内容包括血肉神明的性质、湖心建筑的真实状态、血红极光的来源、未来日志的生成方式，以及序章留言中的前任观测员后来发生了什么。

## 4 唯一的数字摩斯密码

- 数字串：**`0307072340`**，读作 `03-07-07-2340`。
- 格式：`周期-站点-日期-时间`（CC-SS-DD-HHMM）＝ 第 03 周期、第七站、第 7 天、23:40 —— 上一任观测员留下封存记录的时刻。
- 只在 **Day 5 夜里**、手摇发电恢复供电之后到睡觉之前出现；塔内电台（书架顶上）发出微弱嘀嗒声，靠近按 E 收听。错过就没有了（重开当日可以再听）。
- 音频只有数字的摩斯码：两位、两位、两位、四位分组，组间停顿更长；循环播放同一段，直到当夜结束。
- 公平线索链：
  1. 线索 7（Day 4）提前告诉玩家"第五夜电台发数字，记下来"；
  2. 电台面板上贴着数字摩斯对照卡（0–9），并有与声音同步的指示灯（不依赖听力）；
  3. 桌面「站点档案 / SITE 7 ARCHIVE」从 Day 1 起就列出记录编号格式 `CC-SS-DD-HHMM` 和第 03 周期的记录，最后一条 `03-07-07-****` 已封存；
  4. 线索 10 明确指向档案。
- 辅助（设置 → 谜题辅助）：关 / 点划（逐组显示收到的点划）/ 数字（直接显示数字串，不解释含义）。
- 解开 = 在档案里输入该编号（任意分隔符均可）。打开封存记录，`G.persist["morse_solved"] = true`。

封存记录内容（站点记录 + 中止程序）：第七站的工作包括天线、测绘、星图和汇报；第七次汇报后流程转到湖岸；**中止程序**：第七次汇报之前打开天线旁的接线盒，按相反顺序断开蓝、黄、红三根线，经公路离开，不要去湖岸。

## 5 打水 → 湖面回声测绘（流程二）

- 铁皮屋工作台上取便携回声测深仪（取一次即随身）。
- 三个测量点：湖岸木桩 A（x905）、芦苇木桩 B（x945）、栈桥冰洞 C（x984；Day 2 冻住，需要斧子凿开）。
- 每个点：A/D 转动方位，E 发出声脉冲；声脉冲之后才能看到回波强弱（不是实时信号条），方位误差 ≤6° 时记录读数。
- 三条方位线交于湖心同一点。俯视地图坐标（米）：A(−60,0)、B(−20,0)、C(40,6)，声源 (30,220)；方位约 068°、077°、093°。
- 结果自动存为「我的文档」里的 `survey_日期.map`，查看为选做（线索 4、8 的来源）。Day 3 起回波后面有等间距的多次回波（结构）。
- 完成三点后，与原打水相同：约 15 秒入夜。

## 6 三种结局

所有结局之后：游戏标题 → 制作人员 → AI 成员（GLM 5.3 Flash、DeepSeek V4.1 Flash、Claude Opus 5.5、ChatGPT 6.1 Sol）→（好结局：十三年后的场景）→ **结局插画 CG**（最后一张画面）→ 主界面。

结局插画在 `assets/art/cg/`（640×360，独立调色，不经过游戏的 32 色后处理）：

| 结局 | CG 内容 |
| --- | --- |
| 献祭 `cg_sacrifice` | 背影站在栈桥边；布满眼睛的血肉巨星占据天空；湖心正视的血肉教堂；血红极光 |
| 同化 `cg_assimilate` | 正视的教堂沉入冰洞；门开，主角跪在门槛上，两侧是兜帽信徒；序章留言在画面上响起 |
| 逃离 `cg_escape` | 第一人称：橙色手套拨开积雪的灌木，荒废的瞭望塔、铁皮屋、天线和雪埋的皮卡，远处湖心冰面上一圈暗色的环 |

### 坏结局：献祭（`sacrifice`）
保留现有版本：第七次 Yes → 黑屏红字 → 30 秒 → 强制走到湖边 → 镜头拉远，湖心血色教堂、布满眼睛的血星，眼睛逐只睁开 → 爆裂 → 标题与名单 → 主界面。

### 普通结局：同化（`assimilate`）
同样被带到湖边，但不同的场景与结果：血红极光垂落；教堂从冰下升起；观测员自己走上冰面、走向教堂，在门前跪下；门开；教堂连同观测员沉入湖心，冰面合拢，极光熄灭。红字："第 04 周期：流程完成。下一次观测：{yn} 年。" → 标题与名单 → 尾声：黑屏中"语音信箱 - 1 条新留言"，响起序章第一句留言（暗示他成了下一任的"前任"）。

### 好结局：逃离（`escape`）
前提：10 条线索 + 摩斯已解。Day 7 醒来提示"在第七次汇报之前。接线盒。"→ 在提交汇报之前打开接线盒，按蓝、黄、红顺序拔线（顺序错会弹回）→ 红字"观测未完成。请返回观测点。"→ 每天都"打不着火"的皮卡这次能发动 → 驶离，天色转亮，极光褪去 → 标题与名单 → **十三年后**：一伙年轻人在积雪森林深处找到湖边的站点，塔上的窗灯自己亮起，电话提示音响起。

逃离阶段湖岸方向被软阻挡（"不是那边。"），不惩罚。
