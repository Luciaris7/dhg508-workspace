## §1 项目概览

### §1.1 一句话定位【设定】

> 你是加拿大北部山中湖边一座简陋天文瞭望塔的新任观测员。每天给发电机加油、去湖边打水、夜里调试天线、在电脑上记录星图并提交汇报。第七天，你会知道那张星图右上角的小点是什么。

| 项 | 内容 |
| --- | --- |
| 类型 | 2D 横板像素风恐怖游戏 |
| 画风参考 | 《湖边小屋》式像素恐怖；建筑与环境参考《看火人》的瞭望塔 |
| 叙事方式 | 主角无台词，只有内心独白；叙事信息主要由电脑文本、星图、环境变化承载 |
| 单周目时长 | 约 55–70 分钟（序章约 3 分钟 + 7 日 × 约 7 分钟 + minigame 自由游玩 + 结局约 1 分钟） |
| 核心机制 | 光照推进的日常流程 + 真实星图的逐日异常 + 一台 XP 电脑 + 一个叫 The Gift of X 的小游戏 |
| 结局 | 单一结局：血星降临 |

### §1.2 核心体验支柱（用于所有取舍裁决）

| 编号 | 支柱 | 设计含义 | 禁止 |
| --- | --- | --- | --- |
| **E1** | **重复的仪式** | 加油 → 打水 → 天线 → 星图 → 汇报，连续七天；玩家越熟练，异常越刺眼 | 禁止用新玩法填充时长 |
| **E2** | **天色就是进度条** | 完成流程1 转黄昏、完成流程2 转夜晚；开工时必是天黑，玩家用天色读进度 | 禁止脱离流程的时间流逝 |
| **E3** | **他不说话** | 全部情绪由独白承载；独白越少越有力 | 禁止给主角加对话、加 NPC |
| **E4** | **电脑是唯一窗口** | 世界只有一台 XP 电脑能给出信息；恐怖从桌面开始（红字、强制输入） | 禁止把电脑做成普通菜单 UI |
| **E5** | **早已写好** | 未知天体从 Day3 的一个小点长到占据半边天；玩家的所有选择都不改变结局 | 禁止加入"阻止它"的玩法或分支结局 |

3. 音乐音效完全外包，但**需求必须在 W8 前冻结**，否则压缩混音时间。
