## §5 七日内容矩阵（忠实还原设定书脚本）

> 本节逐条对应设定书脚本。`【设定】`= 脚本原文；`【提案】`= 脚本未写明、由本计划补足并需确认（对应 §15 问题号）。

### §5.1 单日 7 分钟标准结构（5 个流程节点 + 睡觉）【设定 + 提案】

| 顺序 | 节点 | 内容 | 完成后 | 时长预算【提案】 |
| --- | --- | --- | --- | --- |
| 0 | 起床 | 黑屏 → 屏幕中心「Day x」→ 塔内房间 | — | 5 s |
| 1 | **流程1** | 下楼至铁皮小屋，给发电机加油 | **户外场景变为黄昏** | 90 s（含往返走路） |
| 2 | **流程2** | 前往湖边打水 | **户外场景变为夜晚** | 90 s（含往返走路） |
| 3 | **夜晚工作 A** | 到屋外调试天线方向 | 天线就位，可开始观测 | 60 s |
| 4 | **夜晚工作 B** | 屋内电脑：打开星图软件 → 记录本日星图 | 可提交汇报 | 90 s |
| 5 | **夜晚工作 C** | 汇报软件：回答 Yes/No → 提交 | 当日工作结束 | 60 s |
| 6 | 睡觉 | 与床互动 → 黑屏 → 次日 | — | 10 s |
| — | 走路与独白 | 场景间移动、独白播放、环境观察 | — | 约 75 s（分散在各节点） |
| — | **合计** | | | **约 7 分钟** |

**设计要点【设定】**
1. 天色是进度条：每完成一项前置流程，天色更暗一档，**开始观测工作时必为天黑**。
2. 玩家在整个主流程中不说话，只有屏幕下方的内心独白。
3. 每日工作内容完全重复，异常只出现在星图与电脑上。

### §5.5 Day5 梦境段规格【设定】

| 步骤 | 内容 |
| --- | --- |
| 1 | 入睡后画面切入 **minigame 的世界**：表现为 minigame 主界面，但**没有现实中的右上角关闭 × 图标**；**只有 start 可以点击**，强制玩家游玩 |
| 2 | 本次游玩中，**礁石障碍被血块一样的礁石取代**；**全程保持难度 1**（不升级） |
| 3 | 玩家游玩约 **40 秒后**，抵达一座漂浮的**血色教堂**（哥特风 + 血肉朋克外观） |
| 4 | 画面表现：教堂自画面**右方**进入，玩家此时只能看到**教堂阶梯的右视图**（保持 2D 侧视玩法） |
| 5 | **自动停船登上教堂** |
| 6 | 玩家沿**阶梯向右上行** |
| 7 | **推开神殿门** → 画面全黑 → 进入 Day6 |

**与数值表的锚点关系**【提案】：难度 1 = 每 10 秒生成 2–3 座礁石（平均 4 秒/座）→ 40 秒内约 10 座礁石 = 约 1000 分。该数值在 §7 中被反向用作难度 1 的时长标定，保证梦境段与自由游玩的手感一致。

## §6 系统规格与验收标准

### §6.1 横板移动与相机【设定】

| 项 | 内容 |
| --- | --- |
| 目标体验 | 走路是"日常"的一部分：不快、有重量、能听见脚步 |
| 关键机制 | 玩家**始终位于画面水平中心**；按 A/D 移动时**背景图层反向滚动**（多层视差）；人物朝向与移动指令一致，**未发出移动指令则停留在最后一次指令的朝向**；场景左右边界限制 |
| 技术方案 | 相机固定于玩家 X；背景分 3–4 层以不同系数平移；玩家自身不产生横向位移的视觉变化（仅动画） |
| 验收标准 | 背景滚动无抖动、无接缝；转向无延迟；边界处无卡墙；60 FPS 下移动速度与动画帧同步（脚不打滑） |

### §6.9 星图（实时读取真实世界行星相对位置）【设定】

#### 6.9.1 需求

| 需求 | 说明 |
| --- | --- |
| 以地球为圆心 | 画面中心为地球，包含太阳系其余几大行星**及其卫星** |

#### 6.9.2 三方案对比（与 v0.9 相同结论）

| 方案 | 实现 | 精度 | 体积 | 性能 | 依赖/许可 | 离线 | 采用建议 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **A 内置历表库实时计算** | VSOP87 截断级数系列开源实现（[Astronomy Engine](https://github.com/cosinekitty/astronomy)：C / C# / JavaScript / Python / Kotlin 同源，官方标称 ±1 角分，无外部依赖，minified JS 约 116 KB，MIT，已对 NOVAS 与 JPL Horizons 做单元测试） | ±1 角分 ≈ ±0.017° | 约 120 KB | 单次全行星计算 <1 ms（可缓存） | 无 | ✅ | **主方案** |
| **B 预生成星表** | 1900–2100 逐日采样（水星–海王星 + 月球）生成二进制表 + 插值 | <0.01° | 200–400 KB | 查表 O(1) | 自研，无第三方 | ✅ | **降级方案** |
| **C 联网 API 校验** | 开发期调用权威星历服务抽样对照 | 权威 | — | 网络延迟 | 仅开发期 | ❌ | **仅验证用** |
