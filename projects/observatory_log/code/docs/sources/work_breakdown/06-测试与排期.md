## §11 测试与验收（每阶段测试任务与标准）

### §11.1 测试策略总览

| 项 | 规定 |
| --- | --- |
| 测试类型 | 文档评审 / 技术验证 / 功能测试 / 回归测试 / 可玩性测试 / 性能测试 / 兼容性测试 / 平衡性模拟 / 冒烟测试 |
| 缺陷分级 | **P0** 阻塞（无法继续/存档损坏/崩溃）；**P1** 严重（流程错误/内容缺失/演出错误）；**P2** 次要（表现瑕疵/文案错误）；**P3** 建议 |
| 收敛标准 | M3：P0=0；M4：P0=0 且 P1<20；M5：P0=0 且 P1<10；M6：P0=0 且 P1<5；M8：P0=P1=0 |
| 自动化测试 | 星图精度对照、minigame 10 万局模拟（含公平约束校验）、存档读写矩阵、英文排版溢出扫描、构建冒烟脚本 |
| 人工测试者 | 内部 2 人常驻 + 外部：M3 招募 3–5 人 / M5 招募 10–15 人 / M6 复测 5 人 |
| 测试记录 | 缺陷编号、严重度、复现步骤、截图/录像、版本号、发现阶段 |
| 数据埋点 | 每日游玩时长、每节点退出点、minigame 局数与分数分布、汇报选择分布、放弃点 |

### §12.5 排期调整规则（触发即执行）

| 触发条件 | 动作 |
| --- | --- |
| W5 结束时 TV-08 或 TV-10 或 TV-14 完成度 <80% | 启用对应降级方案；M2 评审延至 W6 末；P2 起始不变但砍去 VS-11 的 30% |
| W9 时美术实际进度 <85% | 启动 §8.7 路径③范围削减（顺序：血肉变体 → 场景合并 → 结局广角合成化） |
| W13 时 AL-04（梦境段）完成度 <60% | 梦境段时长由 40 秒缩至 30 秒（调整难度 1 的 x 值以保持锚点）；M4 不变 |
| W15 时 AL-08（结局大过场）完成度 <60% | 切换为「静帧 + 运镜 + 音效」版本（56 h → 36 h）；须用户批准 |
| W18 时 5000 分达成率 >1% 或 <0.05% | 按 §7.4 调参杠杆调整并重跑 10 万局；最多 3 轮 |
| W19 时 P0 >0 或 P1 >20 | 停止 PL-07/PL-03 等打磨任务，人力全转缺陷修复，M6 顺延 1 周 |
