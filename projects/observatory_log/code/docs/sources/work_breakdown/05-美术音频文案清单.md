### §9.3 恐怖氛围风格指引（写入音频交付验收）

| 规则 | 具体要求 |
| --- | --- |
| **环境音承担 90%** | 本作大部分时间**没有音乐**；恐怖来自风、水、电流、脚步与沉默 |
| 音乐出现即事件 | 音乐只在 4 个位置出现（菜单 / 序章 / 梦境教堂 / 结局）；一旦响起，玩家就该紧张 |
| 静默是乐器 | 每段恐怖演出前**必须有 2 秒静默**；禁止用音乐掩盖不安 |
| **先闪后声** | 闪电与雷声的延迟必须符合物理（1 秒 ≈ 340 米），Day5 的天线演出尤其依赖这一点 |
| 闪吓节制 | 全流程闪吓（含闪电与画面闪白）≤6 次，且必须服务叙事；禁止在随机交互上触发 |
| 低频优先 | 压迫感放在 20–60 Hz：玩家应"感觉到"而不是"听到" |
| 空间一致性 | 混响与场景物理一致（塔内 0.6 s / 铁皮屋 0.4 s / 教堂 6 s） |
| 人声处理 | 留言用无线电/电话滤波；其余人声一律不可辨识 |
| 响度 | 统一 -16 LUFS（±1），无削波；耳机与音箱双验证 |
