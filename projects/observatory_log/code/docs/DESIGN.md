## 5. 美术

全部由 `tools/art_*.py` 生成，无外部素材（唯一复用：旧版的山羊头骨图标 `tools/src/icon_gift.png`）。主角：深蓝派克大衣 + 毛领兜帽 + 红色毛线帽 + 灰围巾 + 棕色工装裤 + 黑靴（Q-07 未定，此为提案）。

## 6. 音频

全部由 `tools/gen_audio.py` 合成（109 个文件）：约 80 个音效、13 条环境循环、4 首音乐。人声一律不可辨识（Q-39：留言为纯字幕 + 电话提示音 + 磁带底噪）。

## 7. 小游戏平衡

12 档 x 值与升级阈值与清单 §7.4 逐字一致（Q-21/22）。`tools/sim_minigame.py` 用相同生成器与公平约束模拟，5000 分达成率约 34–73%，远高于 M6 目标 0.05–1%。与旧版实测一致——用户当时选了方案 C（保留表格、放宽验收），本次未改数值。调回「几乎不可能」的杠杆：§7.4 顺序 1（安全窗 W）与顺序 3（档 5+ 的 x），见 BREAKPOINT §4 提案 14。

## 8. 已知限制

1. 没有独立 .exe：本机未安装 Godot 导出模板（约 1 GB），目前用 `play.bat` 运行。
2. 合成音频可用，但质感不如专业录音；可同名替换 `assets/audio/` 中的 wav。
3. 星图放大后的卫星位置为圆轨道近似（仅显示用），行星为真实星历。

### 9.3 其他补足的设计

1. 主菜单在通关之前不显示游戏名，让结局弹出的标题成为第一次见到；通关后主菜单显示标题并在天空多一颗小红点（Q-10 提案）。

3. 流程 2：在栈桥边冰洞处按 E，跪下打水 2.4 秒 → 15 秒渐黑。
4. 天线：按住 A/D 连续转（32°/秒），点按微调 1°；±3° 内按 E 锁定；±30° 内指针变黄；每日随机、起始至少偏 60°。
5. Day5 断电放在天线锁定之后、看星图之前。
6. 每日色调（方向 A）：Day1 微暖 → Day2 冷蓝 → Day3 青 → Day4 灰紫低饱和 → Day5 铁灰 → Day6 血红 → Day7 黑红高对比。
