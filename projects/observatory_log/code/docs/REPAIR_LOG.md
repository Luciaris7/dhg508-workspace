## 修复结果

| 游戏名称 | 中文：站点日志；英文：SITE LOG。已更新项目名、标题画面、结局标题、中文字体字形与说明文档；旧的“觐见 / THE AUDIENCE”仍保留在部分剧情台词中，作为世界观文本，不再作为游戏名称。 |

| 问题 | 证据与改动 |
| --- | --- |
| 第七天强制行走可能永久卡住 | 原代码按速度累加位置，只在距离小于 1 像素时结束。长帧会越过目标、反复折返。本次基线中英文通关均在结局入口失败 4 项。改用 `move_toward`，每一步最多走到目标点，保持原速度与剧情。 |
| 启动器只能在作者电脑运行 | `play.bat` 与测试脚本写死 `C:\Users\<用户名>\…`。改为共享查找逻辑：环境变量、工程旁引擎、PATH、WinGet，检查 Godot 4.6+；导入失败时停止启动。 |
| 测试可能假绿 | 菜单测试原先无论断言结果都以 0 退出；批处理只过滤文字，没有传播原进程错误。现在断言失败返回非零，入口同时检查退出码、通过标记与错误信息，保留完整日志。菜单恢复/重开检查等待流程真正完成。 |
| 测试会改玩家存档和设置 | 两个测试入口设置临时 APPDATA / LOCALAPPDATA / XDG_DATA_HOME，结束后恢复环境并清理临时目录。Python 入口每项测试另用独立目录。直接执行场景仍会访问真实存档，应使用隔离入口。 |
| 中英文门禁与说明不一致 | 原 `run_all.bat` 两个通关都未指定语言；现在明确传 `lang=en` / `lang=zh`。 |
| 导出缺少可复用配置 | 新增 Windows / Linux x86_64 预设，显式打包运行时读取的 JSON / BIN；排除工具、截图、文档，数据嵌入可执行文件。 |
| 发布时会混入截图和缓存 | 新增 `.gitignore`，忽略 `.godot`、截图、测试日志、构建产物和本地引擎；源码压缩包也排除这些可再生内容。 |
