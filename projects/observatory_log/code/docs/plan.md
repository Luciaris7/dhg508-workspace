## 1. 一句话与体验目标

> 玩家是加拿大北部白桦湖畔一座瞭望塔的新任观测员，连续七夜记录星图。星图上多出来的那个天体每天靠近一点。
> 全程没有对话、没有战斗、没有追逐；恐怖来自**你正在按要求填写的那份表格**。

体验目标（按优先级）：

1. 前五分钟不觉得是恐怖游戏，只觉得自己在打工；
2. 恐惧来自"例行公事的语气"和"你自己提交的数据"，不是 jump scare；
3. 结束后回看，十条线索都指向同一句话的不同部分；
4. 中英双语读起来是同一本书，不是两个版本。

## 2. 来源：七款游戏，各给了一样东西

| 游戏 | 年份 | 它给了我什么 | 落成的机制 |
| --- | --- | --- | --- |
| 铁肺 Iron Lung | 2022 | 低信息获取 + 克苏鲁式恐惧 | ① 低信息 |
| 无声狂啸 I Have No Mouth | 1995 | 无法逃脱的注定 | ② 不可逃脱 |
| Fears to Fathom | 2021–23 | 日常生活里的异常感 | ③ 日常的异常 |
| 看火人 Firewatch | 2016 | 孤独感与隔离感 | ④ 孤独 |
| Chilla's Art | 2018– | 低画质的恐怖谷 + 日常恐怖 | ⑤ 低画质 |
| Sally Face | 2016–19 | 游戏机里的游戏（屏中屏） | ⑤ 界面内的小游戏 |
| 寂静岭 Silent Hill | 1999– | 心理恐怖 | ⑥ 内在的恐怖 |

三篇学术文献不解释"灵感从哪来"，它们解释这些手法**为什么有效**（见 §3 的④引用栏）：

- Kjeldgaard-Christiansen & Clasen, *Threat Simulation in Virtual Limbo*, JGVW 11:2 (2019) —— 恐怖游戏是有安全边界的威胁模拟；我们怕黑，因为黑暗限制了信息获取。
- Tinwell, Grimshaw & Williams, *Uncanny Behaviour in Survival Horror Games*, JGVW 2:1 (2010) —— 动作与声音的不同步会放大诡异感。
- Kirkland, *Gothic Videogames, Survival Horror, and the Silent Hill Series*, Gothic Studies 14:2 (2012) —— 哥特传统（异世界侵入、碎裂叙事、过去侵入现在）被改写成可玩形式。

## 3. 六种机制怎么落地（以及我的取舍）

### ① 低信息 —— 你只能通过一台很差的仪器看世界

- **来源**：铁肺里你看不见外面，只能靠一台老相机拍照，再凭模糊照片判断。
- **为什么有效**：恐惧来自信息不足，而不是来自看见怪物。
- **我怎么改**：把"拍照"换成**星图**。异常从不画在天空里，只作为星图上的一颗圆存在——第 3 天 6 px，第 7 天 160 px。
- **取舍**：玩家依然"在观察"，但观察的对象是一张每天都在变的图，恐惧来自对比，而不是突发。

### ② 不可逃脱 —— 结局已经写好了，你只是不知道什么时候

- **来源**：无声狂啸，全能的 AI 把最后几个人留下来永远折磨，不给出口也不给死。
- **为什么有效**：恐怖不是"我会不会死"，而是"我知道不会结束"。
- **我怎么改**：七天循环本身就是牢笼。第 6 天起表格**只接受 No**（红字"输入 No"）；第 7 天床失效，玩家被押着走向湖边。
- **取舍**：不锁操作，锁**语义**——你可以乱填，但系统会把 Yes 改写成 No。

### ③ 日常的异常 —— 恐怖发生在你还得继续过日子的时候

- **来源**：Fears to Fathom、Chilla's Art 的路子：普通人的普通一晚，然后有一件事开始不对。
- **为什么有效**：日常的持续让异常显得更不对。
- **我怎么改**：没有任何战斗、追逐或跳吓。你照常加油、打水、上山调天线、填表——异常只是每天多几个像素。

### ④ 孤独 —— 有人说话，但那个人不在

- **来源**：看火人，一个人守瞭望塔，整款游戏只有一个声音，你看不见她。
- **为什么有效**：孤独不是"没有人"，是"只有声音"。
- **我怎么改**：全游戏零 NPC。唯一的人声是开场前任看守的四条语音留言——**而那个人已经走了**。之后只有字。
- **取舍**：看火人给了玩家一个活着的对话者；我把它换成一个已经离职的人。声音还在，人不在。

### ⑤ 低画质与屏中屏

- **来源**：Chilla's Art 的低多边形/低分辨率/VHS 质感；Sally Face 里角色掏出一台真的能玩的掌机。
- **为什么有效**：低画质让细节消失，玩家必须自己填补；屏中屏让恐怖发生在最日常的界面上。
- **我怎么改**：320×180 固定分辨率；桌面是仿 XP 的第二分辨率层，第二天凭空多出一个沾血羊头骨的图标，点开真的能玩（HOMEWARD）。
- **取舍**：Chilla's Art 的粗糙是"做旧"，我的粗糙是像素尺度的硬限制——320×180 下每个元素都必须落在网格上。

### ⑥ 内在的恐怖 —— 怪物在外面，问题在里面

- **来源**：寂静岭，怪物不是随机的，它们长在角色的罪与恐惧上。
- **为什么有效**：真正被审视的不是怪物，是角色。
- **我怎么改**：观测站没有罪案，但有一个**一直在记录、却从不判断的人**。恐怖不是"我做错了什么"，而是"我什么都没做，只是把它写下来了"。

## 4. 我的贡献：把"低信息"从观看变成劳动

铁肺让你拍一张照片去看外面——你仍然是观察者，只是工具很差。
Chilla's Art 让你在店里打工——日常是背景，恐怖是插入的事件。

**这些游戏还没做的一件事**：让记录本身成为劳动。

> 在这款游戏里，你每天亲手把那个东西画进星图，然后给它填一个 Yes。
> 恐怖不来自"我没看清"，而来自"**我看清了，而且我签字了**"。

这也是三种结局的判据为什么落在"线索数量 + 你是否打开了封存记录"上——**签字的完整程度决定你走哪条路**。

## 5. 创作边界（红线）

| 类别 | 规定 |
| --- | --- |
| 地域与年代 | 加拿大北部、针叶林、湖；技术年代是 Windows XP 前后。不出现智能手机、现代 UI、网络用语 |
| 人名地名 | 白桦湖／Birch Lake；上一任观测员**乔瑟夫**。只存在于文本层，改名只动 `txt.gd`／`txt_zh.gd` |
| 语言 | 主角**没有对话功能**，只有内心独白；UI 英文；简体中文是完整第二语言，不是机翻 |
| 呈现 | 一切像素化（世界 320×180、桌面 640×360），32 色调色板 + 抖动 |
| 恐怖手法 | 不解释神明；电台与档案零操作提示；不做追逐战；不使用眼睛元素（已全删） |
| 结局 | 三个：献祭（默认）／同化（唯一入口：第 5 天被血红人影碰到）／逃离（摩斯编号 + ≥8/10 线索 + 修好车） |
| 时间结构 | 七个夜晚 + 序章；真实日期驱动，每 13 年一个周期，"我们是第四个" |

## 6. 构思来回（真实摘录）

早期脚本（`游戏/project 1.docx` → `project 1.1.docx`）定下骨架；之后是两轮真实的驳回与修正，每条都写回正典（`docs/MYSTERY_BIBLE.md` §0）再改代码。

| 用户原话（出处） | 我的理解与改动 |
| --- | --- |
| 「第二日脚印我完全看不见（因为是2D游戏）只能看到互动点」 | 2D 里"远处逼近"不能靠透视，改成**横向推进的雪地脚印 + 互动点**，脚印同时是线索 |
| 「你搞混了后几天中汇报答yes/no的含义…哪怕你确认回答yes，在后面也会被红字强制改为no」 | 站点要的是 **No**：No 被感谢，Yes 被要求"再看一次"随后被改写为 No；第 6 天起只接受 No。**“无异常”是站点要求的记录结果** |
| 「去掉所有有关'眼睛'的设计，包括游戏流程内和结局cg图」 | 全删眼睛元素（含 CG）；血色教堂改为正视、中央单塔 |
| 「不要一团红色糊住整个画面…要能让玩家辨识出原本的世界」 | 侵蚀改为分层叠加，永远保留原世界的轮廓；可互动物品保留原色边缘 |
| 「这个宠物窝意义不明，删去」 | 删除 |
| 「我要玩家几乎不可能拿到5000分」 | HOMEWARD 改为 2000 分到达教堂（约 70% 玩家能到），5000 分那条线删除 |
| 「游戏名不要叫站点日志，和我商量一下改一下」 | 定为《观测日志 / OBSERVATION LOG》；电脑里的小游戏叫 **HOMEWARD** |
| 「三个测绘点分布在三个不同场景…和我讨论，取得我的美术建议后再构建」 | 缩减为两个测量点：北岸船坞栈桥（新场景，带前任残页线索）、站点栈桥冰洞 |
| 「若玩家没完成当日任务就入睡的天数超过三天…进入彩蛋结局」 | 床可随时睡；未完成时先问"还有没做完的事，现在就要睡觉吗？"；这样睡过的天数 ≥4 时，第 6 天入睡后进入 UFO 彩蛋（两张 CG） |
| 「日期只保留前三任的观测记录…封存的档案是13年前的今天留下来的，摩斯密码做对应改变」 | 档案只列 39/26/13 年前三任；摩斯编号 = **13 年前本周期第 7 天的日期 + 23:40**，不再写死常量 |

规则：**凡我自行补足的地方，一律进 `docs/DESIGN.md` §9「待审阅」**，不偷偷变成既成事实。
