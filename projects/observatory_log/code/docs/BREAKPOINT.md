## 6. 踩过的坑（务必记住）

| 坑 | 结论 |
| --- | --- |
| Godot 4.7 Compatibility 渲染器里，**任何自定义 canvas 着色器都收不到 Light2D 光照** | 光照自己做：`world.gdshader` 里环境光 + 8 个点光源（`l0..l7` / `c0..c7` 单独 uniform，**数组 uniform 传不进去**） |
| 该版本 fragment 里的 `COLOR` **已经乘过贴图** | 写 `vec4 tex = COLOR;`，不要再 `texture(TEXTURE, UV) * COLOR`（否则颜色被平方，画面发暗发红） |
| 着色器里 `SCREEN_UV` 在 SubViewport 中不可靠 | 世界坐标用 vertex 里 `MODEL_MATRIX * VERTEX` 传 varying |
| 改了 PNG 后直接运行，Godot 用旧的导入缓存 | **改完资产必须 `--import`**（`play.bat` 和 `tests/run.ps1 import` 会做） |
| `Sky` 是 Godot 内置类名 | 天空类叫 `SkyLayer` |
| PowerShell `Get-Content -Raw` 不加 `-Encoding UTF8` 会把中文写坏；命令行内联引号经常被吃掉 | 改含中文的文件只用编辑工具，或把替换写进 JSON 后用 `tools/patch.py <file.json>`（UTF-8 安全，每条必须唯一匹配） |
| （实际发生过）第一轮用 PowerShell 改过 `README.md` 和 `docs/DESIGN.md`，中文被写成乱码 | 收工前已按当前状态重写两份文档；并全目录扫描，所有文本文件均为有效 UTF-8、无乱码 |
| `.bat` 里 `"%~dp0"` 末尾的 `\` 会转义右引号 | 先去掉末尾反斜杠再传给 `--path` |
| 方舟像素字体 12px 缺少个别常用字（执摇旋然药） | 改用同作者的缝合像素字体 12px（基于方舟补全） |
| 测试与截图脚本会把设置写进 `user://settings.json` | 跑完中文测试后语言会停在中文；这台电脑本来就该默认中文 |
