# Observatory Log (《观测站日志》)

第九週作业：把这款游戏的**恐怖机制**拆开，并说明它们的**文化来源**。

**要回答的问题**：没有怪物、没有事件、不作解释，恐怖靠什么成立？

**答案**：六个机制 — 重复 · 不可知 · 表格 · 缺席 · 界面异化 · 失控 —
以及三篇学术文献（Lovecraft / Carroll / Fisher）。

## 幻灯片

用 [DAIHUM Reslides](https://github.com/boan-anbo/reslides)。源文件在 Reslides 仓库：

- `reslides/examples/starter/slides.md`（副本保存在本目录 `research/outputs/`）
- 图片：`reslides/examples/starter/public/obs/`
- 运行：

```bash
cd reslides
npm run setup      # 首次
npm run dev        # 打开幻灯片，讲者模式 /#/presenter/
```
